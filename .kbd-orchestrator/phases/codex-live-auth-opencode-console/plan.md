The Codex TypeScript SDK spawns the native CLI per turn. Its `startThread`/`resumeThread`, `runStreamed` and `AbortSignal` remain separate from the App Server managed-refresh call. Re-resolve current authorization on each start/resume. Preserve session isolation across process restart. A separately installed HTTP client cannot establish embedded native execution. Deduplicate cumulative text, guard replay cursors, persist idempotent admissions, return 409 on conflicting input and 410 on expired history. Close or reconcile orphaned turns on bounded supervisor shutdown.
